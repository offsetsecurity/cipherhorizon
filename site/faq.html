FAQ

How is this different from testssl.sh or SSL Labs?

Those check one host's TLS configuration very well. CipherHorizon is about where a whole estate stands on post-quantum: a readiness level per endpoint, history, schedules, accounts, machines as well as endpoints, one CBOM and a migration order. It does not send exploit probes; use testssl.sh when you need them.

Does it need the internet?

No. It is one binary with everything inside, and works air-gapped. The reference data (IANA registries, root stores) is compiled in and dated; About shows how old each list is.

What is the TLS hygiene score based on?

Its own rules, shown in full: 100 minus points per cited finding, with caps. See Methodology. It is deliberately not a letter grade.

Can it scan mail servers and databases?

Yes: STARTTLS for SMTP, IMAP, POP3, FTP, XMPP, LDAP and PostgreSQL, chosen by port, by scheme or explicitly.

Will scanning disturb my servers?

A scan makes a few hundred short handshakes, four at a time by default (--concurrency), and can be spaced out (--min-interval). Scan only systems you own or are authorised to test.

Is an inventory script safe to run as root?

It is plain text: read it first. It installs nothing, changes nothing, makes no network connection and never opens a file named like a key. Its SHA-256 can be checked against the binary of the same version.

Who makes it?

Offset Security. It is open source under Apache 2.0.
