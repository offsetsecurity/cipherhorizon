Manual and measured checks (2026-09-21/22, Windows 11, release binary 0.1.0 built from the final source)

1. Restart safety (PRD AC-08.1, AC-12.2)
   - Endpoint with a daily rescan schedule; a slow scan started; server process killed with taskkill /F mid-scan.
   - Restarted on the same database. Log: level=WARN msg="marked scans interrupted by the last shutdown as failed" count=1
   - The scan reads: failed | interrupted by a restart of the server
   - The schedule survived: intervalSeconds=86400, nextScanAt unchanged.

2. List and API performance with 500 endpoints (PRD NFR)
   - POST /api/v1/assets/bulk with 500 lines: 0.17 s, 500 added.
   - 200 sequential GETs each, milliseconds (median / p95 / max):
       GET /api/v1/assets?kind=tls-endpoint   5.6 / 6.8 / 8.4
       GET /api/v1/summary?days=14            3.5 / 4.7 / 5.2
       GET /api/v1/about                      0.4 / 0.8 / 1.2
   - UI: navigation to #/assets until all 500 rows are in the DOM (fetch + build): 40, 50, 51, 51, 54 ms.
     (Excludes browser paint; the pane was not visible so rAF timing was not used.)

3. Scan duration on loopback demo targets (release gate O1: first result <= 30 s)
   - 38 connections against a TLS 1.2 + 1.3 server: 10 to 40 ms. The SSLv3 scripted target: 19 connections, 6 ms.
   - These are loopback figures. On a real network a scan is dominated by round-trip time:
     roughly (connections / concurrency 4) x RTT. The slow demo target (2 s per connection) takes ~20 s.

4. Token prompt (in-app browser)
   - Server with a token: the UI shows the token dialog; a wrong token re-prompts; the right one loads the dashboard.
   - The token is in sessionStorage only (localStorage length 0).

5. Attempted, not achieved
   - Forcing an "incomplete" scan from outside: a 1 s per-connection timeout against the 2 s-per-connection target
     fails the whole scan cleanly ("no response from target ... i/o timeout") instead of producing a partial result.
     The incomplete-scan banner (PRD AC-05.4) is therefore verified by unit tests only, not in the browser.
